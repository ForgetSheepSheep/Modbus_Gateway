# Modbus Gateway

## Directory Layout

- `1.需求文档/Modbus_Gateway/`: gateway design notes, OTA notes, interface references, and configuration examples.
- `1.需求文档/ModbusSlave/`: Modbus slave notes and test commands.
- `2.Code/App_1.0.0/`: original gateway application baseline.
- `2.Code/Bootloader/`: original bootloader baseline.
- `2.Code/Modbus_Gateway/`: organized gateway application and bootloader versions.
- `2.Code/ModbusSlave/`: organized FreeModbus slave examples.

Keil build outputs, local IDE files, debug logs, firmware binaries, and local assistant settings are ignored by Git.
